# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

### 1. Encapsulation
**Encapsulation can be used here to mix the price, name, and quantity in one container. A method for the price, another for the product name, and the quantity will be used in a class to organize them and code inside the method. By applying encapsulation, the methods will be organized inside the class and secure the data inside.**

### 2. Abstraction
**Abstraction will be used to hide the complex processes of the class from the user. In the scenario, hiding the dictionary, methods, and the process on how to print out the receipt from the user is an example of abstraction. By applying abstraction, the user will only be bothered by the frontend of the class.**

### 3. Inheritance
**Inheritance is used to inherit an outside object or all the objects of a parent class. In the scenario, 2 classes can be used, one for a general sari sari store interaction, and the other for the name, quantity, and price, the child class will inherit all the properties of the parent class. By applying inheritance, making classes in one category can be diverse.**

### 4. Polymorphism
**Polymorphism can be used to change the inherited methods of the parent class within the child class. It's a way to be diverse, example from the scenario is I define method order() in the parent class, then modify that same method in the child class to ask about the name, quantity, and price. By applying polymorphism, modifying inherited methods can add diversity, unlike adding features (what inheritance does).**

## Reflection
**Among the four pillars of OOP, the most useful in improving the sari-sari store inventory system is Abstraction. Showing the frontend for the user is the definition of showing the receipt to the consumer/seller. It hides the process of calculations, declarations, and other processes. The reason I did not choose the other pillars for this problem is because Encapsulation in this scenario can be tangling and its data security to be bypassed. The class can be independent eliminating the options for inheritance and polymorphism.**
